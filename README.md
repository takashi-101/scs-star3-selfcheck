# SCS評価制度 ★3 自己点検ツール

経済産業省と内閣官房国家サイバー統括室の「サプライチェーン強化に向けたセキュリティ対策評価制度（SCS評価制度）」の★3について、中小企業や自治体の担当者が自分で点検し、その結果を「SCSセキュリティ専門家」の確認に回せる形で書き出すためのツールです。

★3は「専門家確認付き自己評価」（自分で点検し、専門家が確認する方式）です。このツールが受け持つのは「自分で点検する部分」と「専門家に渡す資料」までで、★3を満たしているかどうかの判定はしません。

## 特徴

- `index.html` 1つをブラウザで開くだけで動きます。インストールは要りません。
- 外部への通信を一切しません（CDNも使いません）。インターネットにつながらない閉域の端末でも動きます。ページ内の Content-Security-Policy で、通信そのものをブラウザに禁止させています。
- 入力したデータは端末の外に出ません。保存と読み込みはJSONファイルで行います。
- 要求事項・評価基準の文言は、経済産業省が公表したExcelファイルから取り込み、書き換えずに表示しています。

## 画面の構成

| 画面 | 内容 |
|---|---|
| 1. はじめに・基本情報 | 使い方、団体名・点検した人・点検の範囲などの基本情報、用語の説明 |
| 2. ★3点検表 | ★3の要求事項（26件）ごとに評価基準（81項目）を並べ、「対応済み／一部対応／未対応／対象外」を選び、根拠メモと証跡（証拠となる文書や画面）の置き場所を書く。上部に分野ごとの進み具合を表示 |
| 3. 外部サービス・委託先台帳 | 1行1サービスで、サービス名、提供元・委託先、預けているデータの種類、件数の規模、管理画面のアカウント管理者、多要素認証（パスワード以外の確認手段）の有無、契約書のセキュリティ条項の有無、止まったときに影響する業務を記録 |
| 4. 停止時の業務切替表 | 1行1業務で、業務名、頼っているサービス（台帳の行から選択）、止まったときの代わりの回し方、切り替えを決める人、連絡先、戻すときの確認事項を記録 |
| 5. 出力 | 専門家確認用の点検結果一覧の印刷（PDF保存）、未対応・一部対応の一覧（要求事項番号つき）、JSONの保存・読み込み |

台帳と切替表は、点検表の次の要求事項の欄から記入状況を参照できます。

- 外部サービス・委託先台帳 → 要求事項 3-1-3（外部情報サービスの管理）と、分野「2. 取引先管理」の要求事項
- 停止時の業務切替表 → 分野「6. インシデントへの対応」「7. インシデントからの復旧」の要求事項

切替表の「頼っているサービス」は台帳の行を選ぶ形にしてあり、同じサービスの書き方が台帳と切替表でずれないようにしています。

## 使い方

1. `index.html` をブラウザ（Microsoft Edge、Google Chrome など）で開きます。ダブルクリックで開けます。
2. 「1. はじめに・基本情報」で団体名などを書きます。
3. 「2. ★3点検表」「3. 外部サービス・委託先台帳」「4. 停止時の業務切替表」を記入します。
4. 作業を終えるときは、画面上部の「点検データを保存（JSON）」で保存します。**保存しないままブラウザを閉じると入力は消えます。** 続きは「保存したデータを開く」で読み込みます。
5. 「5. 出力」の「専門家確認に渡す点検結果一覧を印刷」を押し、印刷先で「PDFに保存」（または Microsoft Print to PDF）を選ぶとPDFになります。

画面上部の「見本データを開く…」から、架空の自治体と架空の中小企業の記入例を読み込めます（`samples/` に同じ内容のJSONがあります）。見本に出てくる団体名・会社名・サービス名・人名はすべて架空です。

## ファイル構成

```
index.html                         ツール本体（要求事項と見本データを埋め込み済み）
scripts/convert_requirements.py    公式Excel → data/requirements.json の変換（標準ライブラリのみ）
scripts/embed_data.py              data/requirements.json と samples/*.json を index.html に埋め込む
data/source/scs_3.xlsx             取り込み元の公式Excel（経済産業省の公開ファイルそのまま）
data/requirements.json             変換後の要求事項・評価基準（取得元URL、取得日、SHA-256入り）
data/retrieval.json                取得の記録（確認したページ、ファイルのハッシュ、更新日時）
samples/                           見本データ（架空の自治体・架空の中小企業）
tests/test_requirements.py         テスト
```

## 要求事項の更新手順

公式のExcelが改訂されたときは、次の手順で取り込み直します。Python 3.9 以降があれば、追加のライブラリは要りません。

```bash
python scripts/convert_requirements.py data/source/scs_3.xlsx --source-url https://www.meti.go.jp/policy/netsecurity/docs/scs/scs_3.xlsx --retrieved YYYY-MM-DD --out data/requirements.json
python scripts/embed_data.py
python -m unittest discover -s tests
```

変換スクリプトは、要求事項番号・評価基準番号の重複や欠番、どの要求事項にもひも付かない評価基準を見つけると、変換を止めて内容を表示します。`data/retrieval.json` の記録もあわせて更新してください。

保存済みのJSONには取り込んだExcelのSHA-256が入っているため、版の違うツールで開くと注意が表示されます。
